sign in

Use a GitHub token for the Hex Modifications repo. Only accounts with write access that are on the owner list can get in. The token stays in this tab and is wiped when you lock, close the tab, or leave it idle for 30 minutes.

how to make a token
  1. Open github.com/settings/personal-access-tokens/new.
  2. Resource owner: Hex-Modifications. Repository access: only select repositories → hex-modifications.github.io.
  3. Permissions: Contents read and write, Actions read and write, and Administration read and write if you want to manage who has access here.
  4. Pick an expiry (90 days is sensible), generate, and paste it above. If GitHub says the organisation needs to approve it, approve it under the organisation's settings.
