/INSTALL

install in a few minutes

your saved files on the sd card aren't touched, and the updater backs up your settings before it flashes anything.

01

right here, one click

on a computer with chrome or edge, plug your flipper in with a data usb cable and press install to flipper next to a release. this page copies the update over usb and your flipper installs it itself.

prefer flipper's own tool? install with flipper lab does the same through lab.flipper.net. close qflipper first: only one app can talk to the flipper at a time.

02

with qflipper

download the .tgz, open qflipper, connect your flipper and choose install from file. pick the .tgz and wait for the restart.

03

from the sd card

extract the .tgz and copy its folder to /update on the sd card. on the flipper, open archive, browse to that folder, select update and choose run in app.

/VERIFY

check the file

every release lists a sha-256 checksum. if the one you compute matches, the file is exactly the one we built.

windows (powershell)

Get-FileHash .\flipper-z-f7-update-*.tgz -Algorithm SHA256

macos

shasum -a 256 flipper-z-f7-update-*.tgz

linux

sha256sum flipper-z-f7-update-*.tgz

/RECOVERY

back to official, any time

  1. uninstall: install the official firmware with qflipper or lab.flipper.net, just like any update. your sd card stays as it is.
  2. frozen flipper: hold left + back for a couple of seconds, then let go to restart it.
  3. won't boot: hold left + back, release back and keep holding left until the led turns blue and the dfu screen appears. connect to qflipper and choose repair.

/TROUBLESHOOTING

something not right?

flipper lab can't find my flipper

use chrome or edge on a computer (not a phone), use a usb cable that carries data, close qflipper and any serial terminals, then reconnect and try again.

an app says "api mismatch"

the app was built for a different firmware version. update the app, or check its page for a build that matches this release. the app compatibility check will flag these for you once it ships.

the update stopped with an error code

the updater checks everything before it writes and can retry safely. restart the flipper and run the update again. if it still fails, use the recovery steps above and reinstall.

will i lose my saved signals, cards or keys?

no. those live on the sd card, which the update doesn't touch, and the internal settings are backed up and restored automatically. backing up your sd card first is still a good habit.

is this from flipper devices?

no. hexfw is an independent project by hex modifications, built on the official flipper zero firmware. it isn't affiliated with or endorsed by flipper devices inc.
