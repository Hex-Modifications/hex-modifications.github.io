Engine and technical specs

What we know and what we expect about the engine GTA VI runs on.

Known

RAGE

GTA VI runs on Rockstar's own engine, the Rockstar Advanced Game Engine (RAGE), which powered GTA IV, GTA V and Red Dead Redemption 2. Fans often call this version "RAGE 9"; Rockstar hasn't used that name.

Estimate

Graphics API

On PC, expect DirectX 12. GTA V's 2025 Enhanced edition and Red Dead Redemption 2 both use it, and RDR2 also supports Vulkan.

Estimate

Ray tracing

GTA V Enhanced added ray-traced shadows, reflections and global illumination. A PC GTA VI will almost certainly build on that.

Estimate

Streaming world

Leonida is far denser than Los Santos, so assets stream in and out constantly. Mods that add a lot of map content will need to respect streaming budgets more than in GTA V.

Estimate

Physics and animation

Rockstar uses Euphoria for character physics and its own systems for vehicles. The Extended Look's weightier driving suggests a reworked vehicle model, which means handling mods will need new tuning.
