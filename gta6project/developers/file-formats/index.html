File formats

GTA V's file formats, and what GTA VI's are likely to look like.

TypeGTA VWhat it isGTA VI estimate
Archives.rpfRAGE Package Files hold almost everything, encrypted on PC. OpenIV and CodeWalker can read and write them.Likely a newer RPF version with stronger encryption.
Models.ydr / .ydd / .yftDrawables (props and buildings), drawable dictionaries (peds and clothing) and fragments (vehicles and breakable objects).Same idea, new versions; expect tools to need updating.
Textures.ytdTexture dictionaries, usually DXT/BC-compressed.Likely BC7 and higher resolutions as standard.
Collisions.ybnCollision bounds for buildings, props and vehicles.Same role.
Map placement.ymap / .ytypWhere objects sit in the world, and the definitions of those objects.Same role, likely more streaming metadata.
Animation.ycdClip dictionaries.Same role.
Audio.awcAudio wave containers.Same role.
Data files.meta / .ymt (XML)Vehicles, handling, weapons and peds are defined in XML-style metadata (vehicles.meta, handling.meta, weapons.meta).Very likely kept: it's how Rockstar's own DLC works.
Scripts.yscRockstar's compiled game scripts, which call engine "natives".Same model, with a new native table to map out.
Estimate

Read this first

The left-hand columns describe GTA V on PC, which is well documented. The last column is our estimate for GTA VI. No GTA VI files have been officially released for PC.
